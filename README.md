# Отчёт об использовании ИИ

**Инструмент**: ChatGPT.
**Промпт**: «Напиши JavaScript-код, который загружает данные из опубликованной Google Таблицы (CSV) через fetch() и выводит их на страницу в виде HTML-таблицы. Обработай ошибки через try/catch.»

**Что ИИ сделал правильно**: базовая структура с async/await и try/catch была корректной.

**Что пришлось исправлять**: 
1. В сгенерированном коде отсутствовала проверка `response.ok`. Если ссылка неверная, fetch возвращает 404, но код продолжает парсить HTML-страницу ошибки как CSV. Я добавил `if (!response.ok) throw new Error(...)`.
2. Парсинг CSV не учитывал символ `\r`. Из-за этого в конце строк могли появляться лишние символы. Исправлено на `split(/\r?\n/)`.
3. Ошибка выводилась только в консоль, поэтому при сбое страница просто оставалась пустой. Я добавил вывод сообщения об ошибке на саму страницу.

**Чему научился**: проверять не только наличие try/catch, но и корректность проверки HTTP-статуса (response.ok). А также понял, что браузер блокирует fetch-запросы (CORS), если открывать HTML-файл просто двойным кликом, поэтому нужно использовать локальный сервер (Live Server).
